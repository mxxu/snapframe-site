# snapframe-site

Product website for the Snapframe Chrome extension, served by GitHub Pages.

- `index.html` — landing page
- `privacy.html` — privacy policy (required as a public URL by the Chrome Web Store)

## Updating

Edit the files and push to `main`; Pages redeploys automatically.

URLs still marked as TODO in the HTML (store listing, checkout link, support
email) get filled in as those become available.
